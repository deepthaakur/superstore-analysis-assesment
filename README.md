# Global Superstore Data Analysis

## Project Overview

This project analyzes the Global Superstore dataset to identify business opportunities, sales trends, profitability, customer segments, regional performance, and the impact of discounts on profit.

## Dataset Information

* **Dataset:** Global Superstore Dataset
* **Source:** Kaggle
* **Records:** 51,290
* **Columns:** 27

## Tools Used

* Python (Pandas)
* Google Sheets
* Google Looker Studio

## Data Cleaning

* Checked missing values.
* Checked duplicate records.
* Converted date columns to datetime format.
* Identified outliers in Sales, Profit, Discount, and Quantity.

## Key Business Insights

1. Technology category generated the highest sales and profit.
2. Central region performed best in sales and profitability.
3. Higher discounts reduced profitability.
4. Consumer segment contributed the highest revenue.
5. Sales and profit increased consistently from 2011 to 2014.

## Recommendations

* Reduce discounts above 50%.
* Increase investment in Technology products.
* Apply successful Central region strategies to lower-performing regions.
